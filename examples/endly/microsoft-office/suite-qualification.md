## Acceptance tasks

- Excel: open source data, analyze it, create a separate summary workbook with
  formulas, formatting and a chart; save, reopen and independently verify
  calculations, structure and presentation. Preserve source hashes.
- Word: inspect a source document, make targeted edits preserving neighboring
  content, apply styles, tables and page layout, save a new DOCX, export PDF,
  reopen and independently verify content and rendered layout.
- PowerPoint: create a presentation from verified analysis, add/edit slides,
  text, tables/charts and layouts; save PPTX, export PDF, reopen and inspect
  slide structure and rendered output.
- Outlook: inspect/search authorized folders and conversation threads; draft
  professional new messages and replies appropriate to the supplied context;
  save and reopen drafts; attach Word, Excel, PowerPoint and PDF outputs with
  verified names, sizes and artifact identity. Verify sender account, recipients,
  subject, body, reply/thread context and attachments before requested sending.
  Sending to another person requires explicit user instructions; a request to
  build the capability is not authorization to send an unspecified message.
  Use a controlled mailbox for delivery tests when authorized. Confirm sending
  from server/Sent Items evidence where available, not from a successful button
  click. An uncertain send must be reconciled before any retry to prevent
  duplicate messages. Exercise interrupted attachment and send operations.
- OneNote: use an authorized disposable notebook/section, create and edit a
  structured page, reopen it and verify its content. Determine supported
  export and synchronization evidence through actual app discovery.
- Cross-application: carry verified Excel analysis into Word and PowerPoint,
  and prepare an Outlook draft referencing the resulting artifacts. Retain
  artifact identity, provenance and checkpoints across application boundaries.

For every case, exercise interruption and resume without repeated edits,
changed focus, modal dialogs, stale references, unavailable permissions and
save/export uncertainty. A task passes only when independent results match the
original request; successful input dispatch alone is insufficient.
